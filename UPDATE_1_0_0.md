# 1.0.0 — personal practice and review

The user-approved 0.2.2 pronunciation and speech engine are retained. This update adds independent plans per player, explicit sound-tag content selection, separate language banks, recent-content avoidance and difficult-item review, resumable quests, clearer speech states, collapsible adult help, ordered listening prompts, balloon readiness/rest/assistance cues, active-player identity and next-quest suggestions.

The adult area now separates Results, Practice settings and Backup/information. Every completed session is reviewable. Reporting separates recognition matches, adult approvals, retries, skips and touch assistance. Backup uses Android's document picker, validates and previews imports, and keeps a recovery copy before replacement. Child screens revoke the grown-up gate so navigating back cannot accidentally reopen player management.

Original players, ages, XP, badges and completed sessions migrate in place. Each profile initially inherits a separate copy of the previous shared settings. No uninstall is needed; it would erase local data. See START_HERE.md and VALIDATION.md for installation, checks and remaining device acceptance.
